# 九九チャレンジ：小学生向けMVP Ver 2.0

**対象**: 小学2年生（九九苦手層） / **コンセプト**: 成功体験 > 競争

---

## 📱 パイロット版の特徴

### ✅ 実装済み機能（P0）

1. **🎤 音声読み上げ（Web Speech API）**
   - セル選択時：「{a}かける{b}は？」
   - 正解時：「すごい！」
   - 設定：ja-JP / rate 0.8 / pitch 1.1

2. **💾 進捗保存（localStorage）**
   - 正解・不正解カウント
   - 弱点ペア（weakPairs）の自動保存

3. **📊 弱点可視化**
   - 不正解：重み +1
   - 正解：重み -0.5（下限0）
   - Top3を画面上部に表示

4. **🔢 テンキー改善**
   - ボタンサイズ：64×64px（タップしやすい）
   - 「OK」ボタン：緑色で強調
   - 「⌫」ボタン：黄色で強調
   - Enter キー = OK

5. **📴 PWA対応**
   - オフライン起動可能
   - ホーム画面追加可能
   - manifest.json + service worker

## 🚀 使い方

### ローカル起動
```bash
# HTTPサーバーで開く（Service Worker動作には必須）
python3 -m http.server 8000
# または
npx serve .
```

ブラウザで `http://localhost:8000/index.html` を開く

### 動作確認手順
1. ページを開く → 音声許可を求められる場合は許可
2. 任意のセルをクリック → 「{a}かける{b}は？」と読み上げ
3. テンキーまたはキーボードで入力 → 「OK」または Enter
4. 正解：緑背景 + 「すごい！」+ 次のセルへ自動移動
5. 不正解：赤背景（再入力可能）
6. 複数回間違えると → 上部に「苦手な問題 Top3」が表示される
